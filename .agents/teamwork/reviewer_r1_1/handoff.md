## 2. Issues Discovered and Rectifications Applied

### Issue 1: Viewport Scroll Offset in Visual Editor Capture Scripts
- **Input**: Inspecting the editor screenshots (`01_adm_editor_page1_light.png` and `02_adm_editor_final_sheet_light.png`) generated by the prior attempt.
- **Expected**: Full, unclipped view of the A4 document page showing the BukSU logo and title in screen mode.
- **Actual**: In `01_adm_editor_page1_light.png`, the left ~250px of the document sheet was partially cropped because `scrollIntoViewIfNeeded()` in a 900px viewport scrolled the document under the sidebar and vertically offset the top header before taking the element screenshot.
- **Root Cause**: Playwright's `scrollIntoViewIfNeeded` on an element taller than the viewport (1050px > 900px) aligned to the center/bottom of the element rather than `{ block: 'start', inline: 'center' }`.
- **Fix**: Re-executed targeted Playwright capture scripts with `{ block: 'start', inline: 'center' }` and captured `fresh_page1_aligned.png` and `fresh_page2_aligned.png`. Replaced the cropped screenshots in `scratch/screenshots/adm_print/` and copied them into the current active conversation artifact directory (`5ada59db-c4c6-4a30-8e5e-10008bc0d6b9`).

The implemented 18mm margin exceeds the standard 3mm–5mm office printer margin by >3x.
