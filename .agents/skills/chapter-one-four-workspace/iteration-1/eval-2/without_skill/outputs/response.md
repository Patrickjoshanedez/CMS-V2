## Chapter 3: Methodology

The study adopts a developmental-evaluative design, with Agile used to organize iterative system development. Planned activities should connect requirements identification, implementation, review, and revision, while maintaining records of the requirements addressed and changes made during each iteration. Evaluation should separately examine system behavior through documented tests and participant perceptions through the existing instrument, which adopts ISO/IEC 25010:2011. Adoption of this framework does not establish certification. The statement describing the system as “ISO 2023 certified” is unsupported and should be removed.

The study plan specifies 37 participants, whereas a later summary reports 77. Without recruitment and participation records, neither the actual sample size nor the reason for the discrepancy can be verified. The manuscript should retain the planned sample as a planning detail and identify the reported total as unresolved. Recruitment method, eligibility criteria, invitations, consent, completed responses, exclusions, and final analyzable sample must be documented before reporting an achieved sample.

## Reproducible test-record pattern

For each test, record: test ID; linked requirement and objective; system version; environment and configuration; test date and executor; preconditions; input data; ordered steps; expected result; acceptance threshold established before execution; actual result; evidence location; pass/fail decision; defect reference; and retest outcome. Timing tests additionally require workload, measurement boundaries, repetitions, and aggregation rules. Unexecuted cases must remain marked “not executed,” with actual results and verdicts blank.

## Remaining gaps

No executed tests or supporting logs were supplied. Consequently, no functional pass rate or technical compliance conclusion can be reported. An “Excellent” questionnaire classification describes a score under its specified interpretation scale; it does not mean all tests passed. The scale boundaries, scoring rules, instrument provenance, and reconciliation of participant counts remain necessary for a reproducible final methodology.
