# Archive Batch Ingestion Troubleshooting Matrix

Exact failure signatures encountered during live browser archival on CMS-V2, why they occur, and how to fix them cleanly.

| Symptom / Log Signature | Root Cause | Fix |
| :--- | :--- | :--- |
| `HTTP 400 MulterError: Too many fields` on `POST /api/projects/archive/bulk` | `createMemoryUpload` defaulted `limits.fields` to `10`, while the upload form sends 12+ text/boolean fields. | Parameterize `maxFields` in `server/middleware/upload.js` and pass `50` for `archiveDualUpload`. |
| `HTTP 413` / `File exceeds maximum size of 25MB` on legitimate 35–45 MB theses | Shared `MAX_UPLOAD_SIZE_MB = 25` blocked large archival PDFs while chapter submissions must stay 25 MB. | Add `MAX_ARCHIVE_UPLOAD_SIZE_MB = 50` in `server/config/env.js` and use it in `validateDualArchiveFiles` & `validateMetadataFile`. |
| `[OcrExtractionService] Microservice call failed (Timeout after 20000ms)` during `bulkUploadArchive` | `extractText.js` called `ocrExtractionService.parseDocument` without `{ mode: 'metadata' }`, triggering expensive full-page `find_tables()` on 40 MB PDFs inside `POST /archive/bulk`. | Pass `{ mode: 'metadata' }` from `extractText.js` (which only consumes `parsed.fullText`), skip `find_tables()` in `ocr_engine/app.py` when `mode == "metadata"`, and run OCR in `asyncio.to_thread`. |
| Extracted metadata contains `<!-- ... -->` HTML comment markers | PyMuPDF/PaddleOCR markdown output wraps table/block hints in HTML comments. | Strip `/<!--[\s\S]*?-->/g` in `ocr_engine/app.py`, `pdfMetadataExtractor.js`, and `extractText.js`. |
| `.docx` fails metadata extraction or `temp-extractions/*.pdf` throws `Invalid PDF` | `/api/documents/extract-pdf-metadata` hardcoded `application/pdf` validation and `.pdf` temp file extension. | Route through `validateMetadataFile` (PDF + DOCX), resolve dynamic extension (`.docx`/`.pdf`) in `document.controller.js`, and extract DOCX text via `extractText` in `metadataExtraction.service.js`. |
| Legacy `.doc` hangs or crashes parser | Binary OLE2 header `d0cf11e0a1b11ae1` is not OOXML zip (`PK`) or PDF (`%PDF-`). | Reject `.doc` clearly in `ExistingCapstoneUploadPage.jsx` ("Legacy .doc files are not supported...") and backend magic-byte validation. |
| `#courseId` missing `BSEMC` or `#academicYear` missing pre-2024 years (`2010`, `2020`) | Only `BSIT` and recent academic years (`2024–2026`) exist in seeded DB. | Ensure `BSEMC` exists via `/api/academics/courses`, and merge historical years (`2005..nextYear`) + extracted year into `academicYearOptions` in `ExistingCapstoneUploadPage.jsx`. |
| Deduplication check returns `0` archived papers (`HTTP 400 limit: Too big`) | `/api/projects/archive/search` Zod validator rejects `limit > 50`. | Paginate `?limit=50&page=1..N` in browser evaluation until `page >= totalPages`. |
| `cms-plagiarism-api` logs `TypeError: PlagiarismEngine.index_document() got an unexpected keyword argument 'document_id'` | `_run_inprocess_index` in `plagiarism_engine/main.py` passed raw kwargs instead of `IndexRequest(...)`. | Pass `IndexRequest(document_id=..., text=..., metadata=...)` and rebuild `plagiarism_api`. |
| `cms-plagiarism-api` logs `RuntimeError: The size of tensor a (708) must match the size of tensor b (512)` | `embeddings.py` blindly assigned `self._model.max_seq_length = 8192` even when running `all-MiniLM-L6-v2` (512 position embeddings). | Clamp `SentenceTransformer.max_seq_length` against `auto_model.config.max_position_embeddings` (`usable_pos - 2` for RoBERTa variants). |
| Playwright hangs at `goto` or times out after 120s | Using `waitUntil: 'networkidle'` (blocked forever by polling/Socket.IO) or running >5 papers per process. | Always use `waitUntil: 'domcontentloaded'`, set a `115s` script watchdog with `browser.close()` in `finally`, and process sequentially in `--limit=5` slices. |
| `GET /api/submissions/archive-document/file -> 400` in archived manuscript viewer | `CanonicalDocumentViewer` passes synthetic `_id: 'archive-document'` + in-memory `fileBlob`, and `SophisticatedDocumentViewer` still attempted a backend fetch for DOCX blobs. | Treat `'archive-document'` as synthetic in `SophisticatedDocumentViewer.jsx` and short-circuit `isDocx && effectiveFile` before `shouldFetch`. |
