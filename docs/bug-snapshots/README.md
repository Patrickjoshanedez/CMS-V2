# Bug Snapshots

Store screenshots and short recordings referenced from [../BUG_REPORTS.md](../BUG_REPORTS.md).

Naming: `BUG-<ID>_<step>_<light|dark>_<desktop|mobile>.png`, for example `BUG-007_01_dark_desktop.png`.
Console or network captures: `BUG-<ID>_<step>_console.png` or `BUG-<ID>_<step>_network.png`.

Do not include secrets, tokens, or unblurred personal data.
